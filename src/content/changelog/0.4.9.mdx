---

Chiku now works with AI browser agents. Tools like Claude, ChatGPT, Gemini,
Cursor, and Copilot can discover what chiku can do and act on your behalf —
creating tasks, adding them in bulk, and deleting them with your confirmation —
without scraping the screen.

### Added

- **`hello_chiku`** — a quick health check so an agent can confirm it's talking
  to chiku.
- **`add_task`** — create a single task in a project, with an optional title,
  description, status, and assignee. Defaults to the project you're viewing.
- **`bulk_add_tasks`** — add many tasks at once, either as a list of titles or
  full task objects. Partial failures are reported instead of aborting.
- **`delete_task`** — delete a task by id or reference number. Always asks you
  to confirm before deleting; cancelling leaves everything untouched.

### Improved

- Project lookup by name or slug now resolves to the right project instead of
  guessing the first one.
